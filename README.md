# 个人学习周报

**周期**：2026年10月26日 至 2026年11月2日
**学习主题**：NLP 文本处理体系、RNN/LSTM/GRU 序列模型、PyTorch 注意力计算实现与 Seq2Seq 论文精读

---

### 一、 本周核心学习成果

1. **NLP 文本处理与特征工程体系**：
   - **文本处理基本方法**：掌握分词（jieba）、词性标注与命名实体识别（NER）基础方法。
   - **文本张量表示方法**：掌握 One-Hot 编码、Word2Vec（CBOW / Skip-Gram）词向量训练及 Word Embedding 稠密张量映射。
   - **文本数据分析与特征处理**：完成标签分布、句长分布与词频统计分析，掌握 n-gram 特征提取、文本长度规范（截断与填充）及回译数据增强方法。

2. **RNN 及其变体序列建模与实践**：
   - 深入理解传统 **RNN、\*\***LSTM（遗忘门、输入门、输出门与细胞状态）**与 **GRU（重置门、更新门）\*\*的内部结构与门控记忆机制，缓解长序列梯度消失问题。
   - 完成传统 RNN、LSTM 与 GRU 序列模型的前向网络搭建、多维时序张量输入输出及隐状态传递验证。

3. **注意力机制与 PyTorch 计算实现**：
   - 深入理解**注意力机制原理**、Q/K/V 三角色语义及注意力权重分配计算规则。
   - 基于 PyTorch 完成三维张量批量矩阵乘法实操，掌握利用 Softmax 归一化权重与矩阵加权求和实现注意力机制的核心计算流程。

4. **核心文献精读：Seq2Seq 开山论文**：
   - 精读 Sutskever et al. (2014) 《Sequence to Sequence Learning with Neural Networks》。
   - 理解基于LSTM 构建 Encoder-Decoder（编码器-解码器）端到端序列映射框架的核心思想。
